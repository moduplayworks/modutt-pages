# modutt-pages

MODU TT 웹 UI의 **배포 산출물만** 받는 공개 저장소입니다. 소스와 workflow는 private `moduplayworks/modutt-mono`에 있고 여기서는 아무것도 빌드하지 않습니다.

- 게시 branch: `gh-pages` (generated-only)
- 게시 주체: `modutt-mono`의 검증된 `apps/web/dist`
- 각 게시본의 출처는 `deployment.json`의 `source_repository`, `source_sha`, `version`에서 확인합니다.

이 저장소에 직접 commit하지 마세요. 변경은 `modutt-mono`에서 시작합니다.

## 라이선스와 문의

제품 문의와 이슈는 [modutt-mono](https://github.com/moduplayworks/modutt-mono)에서 다룹니다.
